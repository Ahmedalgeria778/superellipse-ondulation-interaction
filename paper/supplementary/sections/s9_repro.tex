\section{Data and reproducibility note}
\label{suppsec:repro}

The scalar results are stored as JSON files in the directory \texttt{results/scalars/}, one file per simulation, and are flattened into \texttt{results/scalars\_clean.csv} by \texttt{solver/make\_scalars\_csv.py}. The figures and tables of the main text are generated directly from the JSON files; the CSV is a convenience index for inspection. Records whose \texttt{status} is neither \texttt{converged} nor \texttt{reanalyzed} (runs stopped by an iteration cap) are listed by the script but excluded from the CSV, so they cannot enter a fit or a table. Each JSON file contains the following fields: \texttt{Re}, \texttt{n}, \texttt{alpha}, \texttt{N}, \texttt{P\_star}, \texttt{D\_star}, \texttt{K\_star}, \texttt{fluid\_area}, \texttt{Ma}, \texttt{iters}, \texttt{residual}, \texttt{status}. The velocity fields are stored as NumPy \texttt{.npz} files in \texttt{results/fields/}, with arrays \texttt{ux}, \texttt{uy}, \texttt{rho}, \texttt{fluid} (boolean mask), and the grid coordinates \texttt{xc}, \texttt{yc}.

All figures in the main manuscript and in this supplementary material were generated from these files using Python scripts with Matplotlib. The sign conventions, normalizations, and contrast definitions used in the scripts are exactly those stated in the main manuscript (Sections~II.E and~II.G).

\paragraph{Public repository and archived release.}
The solver (MRT collision, pull streaming, half-way bounce-back, Bouzidi interpolated bounce-back, lid momentum injection), the geometry and diagnostic modules, the FEM Taylor--Hood solver, the campaign drivers, and all post-processing scripts are version-controlled at
\begin{center}
\url{https://github.com/Ahmedalgeria778/superellipse-ondulation-interaction}
\end{center}
(MIT licence). The version corresponding to this manuscript is release \texttt{v1.1.0},
\begin{center}
\url{https://github.com/Ahmedalgeria778/superellipse-ondulation-interaction/releases/tag/v1.1.0}
\end{center}
which distributes the raw converged LBM fields (244 \texttt{.npz}, including the fourth level at $N=768$ for $n=2$ and $n=4$ at $Re=100$) and the native and grid-sampled FEM fields (34 \texttt{.npz}, including $Re=1000$, $n_x=256$ and $Re=400$, $n_x=32$) as the archive \texttt{superellipse\_lbm\_fem\_fields\_v1.1.zip} (278 files, $\approx287$~MB, archive SHA-256 \texttt{f2f06790}\ldots\texttt{20a755d0}). The release also includes \texttt{MANIFEST.txt}, which lists the byte size and the full 64-hex SHA-256 digest of every file in the archive, together with the dataset \texttt{DATA\_README.md}. The scalar budgets (\texttt{results/scalars/}, one JSON per converged run, flattened into \texttt{scalars\_clean.csv} by \texttt{solver/make\_scalars\_csv.py}), the contrast tables, and the exact four-band $\mathrm{d}A/\mathrm{d}B$ partitions are stored in the repository and are the direct source of every number quoted in the article. A DOI-bearing Zenodo snapshot of the \texttt{v1.1.0} tree will be added upon acceptance; until then the tagged GitHub release is the citable, immutable version.
